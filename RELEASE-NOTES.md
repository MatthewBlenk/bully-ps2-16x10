# Revision 4 — first public test release

16:10 camera projection and native interface scaling for Bully PS2 USA, SLUS-21269, CRC 28703748.

Tested with ARMSX2 macOS build 112cd677b4, Metal, on a MacBook Air M4. The main camera ratio measured approximately 1.6; the clock and minimap appeared circular in inspected gameplay.

Required settings: in-game Wide (16:9), emulator aspect ratio Auto, vertical stretch 100%, no cropping. Disable nemesis2000's 16:9 patch and automatic widescreen patches for this game.

The selectable patch group remains “Bully 16:10 Projection v3”; its contents are revision 4. See README for installation and save-state handling.

This is a community test release. All missions, menus, cutscenes, minigames, and special cameras have not been exhaustively tested. Other regions and emulators remain unverified.
